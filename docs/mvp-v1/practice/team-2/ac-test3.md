### TC-002-01: 高價值功能標籤顯示

| 欄位 | 內容 |
|:---|:---|
| **測試案例編號** | TC-002-01 |
| **測試目標** | **驗證高價值功能（價值分數 >= 8）於功能列表中正確顯示「高價值」標籤，且標籤顏色為綠色** <br> <span style="color:#22c55e;font-weight:bold;">（Tailwind: bg-green-500, text-white）</span> |
| **相關 User Story** | 作為產品團隊成員，我希望高價值功能能以明顯標籤顯示，方便聚焦資源 |
| **相關 AC 場景** | 高價值功能的視覺標籤 |
| **設計稿/參考圖** | ![高價值標籤設計](../assets/DEMO-green-sprint-progress.png) |
| **測試前置條件** | 1. 儀表板已載入所有功能資料<br>2. 至少有一項功能的價值分數 >= 8<br>3. 使用者已登入並可檢視功能列表 |
| **測試步驟** | 1. 開啟儀表板功能列表頁面<br>2. 等待所有功能資料載入<br>3. 檢查價值分數 >= 8 的功能列<br>4. 檢查該列是否顯示「高價值」標籤<br>5. 驗證標籤顏色是否為綠色且明顯 |
| **預期結果** | 1. 所有價值分數 >= 8 的功能均顯示「高價值」標籤<br>2. 標籤顏色為綠色（#22c55e），且與其他標籤明顯區隔<br>3. 其他分數 < 8 的功能不顯示該標籤 |
| **測試資料** | 功能A: value_score=9<br>功能B: value_score=7<br>功能C: value_score=8 |
| **測試類型** | 功能測試（視覺驗證） |
| **自動化程度** | 半自動（需人工確認顏色與標籤） |

### TC-002-02: 高價值標籤邊界值測試
