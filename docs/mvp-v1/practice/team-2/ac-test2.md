## 📋 User Story 回顧

**US-001**: 作為產品經理，我希望在儀表板上看到每個功能的價值分數，並能依分數排序或篩選，以便快速辨識高價值項目並優先安排開發。

---

## 🎯 功能說明

在 Jira Dashboard 的功能列表中，為每個功能（Issue）顯示一個「價值分數」，協助團隊聚焦高價值項目，避免資源浪費於低價值功能。

---

## 🔄 流程描述

1. 使用者開啟儀表板，系統自動載入所有功能（Issue）資料。
2. 前端向後端 API 請求功能清單，後端從 Google Sheets 取得每個功能的 `value_score` 欄位。
3. 前端於每個功能列顯示對應的價值分數。
4. 使用者可依價值分數排序或篩選功能清單。

---

## 📊 資料來源

- **Google Sheets 表格**: 必須包含 `value_score` 欄位（數值型，建議 1-10 分或 0-100 分）。
- 欄位名稱可配置，預設為 `value_score`。

---

## 🎨 UI/UX

- **功能列表**: 每列右側顯示「價值分數」欄位。
- **顏色區分**: 分數以顏色區分（如：高分綠色、中分黃色、低分紅色）。
- **分數明細**: 滑鼠懸停分數時，顯示分數計算依據（如有多欄加權，顯示明細）。
- **排序與篩選**: 支援依分數排序與篩選。

---

## ✅ 驗收標準 (Acceptance Criteria)

### AC01: 顯示功能價值分數
```gherkin
場景：儀表板顯示功能價值分數
Given 儀表板已載入所有功能的資料
When 使用者檢視功能列表
Then 每項功能應顯示對應的價值分數（例如：1-10 分）
And 分數應基於 Google Sheets 中的 "value_score" 欄位計算
```

### AC02: 分數排序與篩選
```gherkin
場景：依價值分數排序與篩選功能
Given 儀表板已載入所有功能的資料
When 使用者點擊「排序」按鈕或設定篩選條件
Then 功能列表應依分數高低排序或僅顯示符合條件的項目
```

### AC03: 分數明細顯示
```gherkin
場景：查看分數計算明細
Given 儀表板已載入所有功能的資料
When 使用者將滑鼠懸停於某功能的價值分數上
Then 顯示該分數的計算依據與來源描述
```

---

## ⚠️ 例外/邊界情境

- **缺少分數資料**: 若 `value_score` 欄位缺漏，顯示「-」或提示「尚未評分」。
- **資料連線失敗**: 若 Google Sheets 連線失敗，顯示錯誤訊息並允許重試。

---

## 🛠️ 技術備註

- **後端需求**: 支援 Google Sheets API 連接與快取。
- **前端需求**: 支援分數顏色渲染與排序互動。
